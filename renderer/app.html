      Connect your tablet

      1. Plug your reMarkable into this computer with a USB cable.
      2. Wake it up and unlock it.
      3. On the tablet, turn on Settings → Storage → USB web interface.
      4. On this Mac, allow the app in System Settings → Privacy & Security → Local Network (when running from source: allow your terminal app).

          Deleting notes

          A note would be downloaded into _deleted in the save-to folder before it's removed from the tablet.

          Not available yet: the reMarkable USB web interface can list, download and upload notes, but it can't delete them.
